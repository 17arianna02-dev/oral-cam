Ver esta pantalla en la TV

Enviar la pantalla a un televisor es una función del sistema/navegador, no de esta app — pero aquí tienes las formas más confiables según lo que tengas en tu consultorio:

📡 Chromecast o TV con Google TV
En Chrome, clic en los tres puntos (⋮) arriba a la derecha → "Transmitir..." → elige tu TV.

🍎 Apple TV (Mac)
Centro de Control → Pantalla → AirPlay → elige tu Apple TV.

🖥️ Windows con Miracast
Tecla Windows + K → elige tu TV.

🔌 Cable HDMI
La opción más simple y sin cortes: conecta la computadora a la TV y duplica pantalla.

El botón de arriba solo funciona si tienes un Chromecast en la misma red Wi-Fi y usas Chrome o Edge; si no aparece nada, usa una de las opciones manuales.

Análisis de imágenes con IA

El botón 🔬 Analizar le pide a la IA de Anthropic que describa posibles hallazgos visuales (manchas, posibles caries, placa, desgaste, etc.) como apoyo preliminar, nunca como diagnóstico.

Mientras uses esta app dentro de claude.ai, funciona automáticamente. Si la subiste a tu propio sitio (por ejemplo GitHub Pages), necesitas pegar aquí tu propia clave de API de Anthropic para activarla — el uso se cobra a tu cuenta de Anthropic.

La clave solo se guarda en la memoria de esta pestaña, nunca se envía a ningún otro lugar y se pierde al cerrar o recargar la página. No la actives en computadoras compartidas o públicas.

Abrir esta app en el celular

Escanea con la cámara del celular para abrir esta misma app. Nota: cada dispositivo guarda sus propias capturas — las de este computador no se copian solas al teléfono, usa "Enviar al teléfono" para eso.

Marcar hallazgo

Elige una forma y haz clic sobre la imagen para marcar un punto de interés (por ejemplo, una caries o grieta). Puedes marcar varios puntos, incluso con formas distintas.
